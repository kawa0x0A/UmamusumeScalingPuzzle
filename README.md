# ウマ娘パズルゲーム (ファンメイド)

ウマ娘モチーフのスイカゲーム風落ちものパズル。**非公式のファンメイド作品です。**
同じウマ娘を 2 人くっつけると次の子に進化し、U 字ケースの上限を越えるとリタイア。

ブラウザだけで動きます（ビルド不要）。

## 起動

```bash
node tools/serve.mjs
```

`http://localhost:5173/` を開いてください。`index.html` を直接開いても動きます。

アイコンは公式ポータルサイトが配布している SNS 用アイコンを、実行時に URL から直接読み込みます。
画像はリポジトリに持たないので、初回表示時のみネットワーク接続が必要です
（CDN 側で 1 年キャッシュされるため 2 回目以降は即座に表示されます）。

## 画面の流れ

タイトル（＝メンバー選択）→ プレイ → リタイア、の 3 状態です。
音は最初の「スタート」を押した時点から鳴り始めます（ブラウザの自動再生制限のため）。

| 場面 | 音 |
| --- | --- |
| プレイ中 | 120BPM・16 小節（32 秒）ループの BGM |
| タイトル → プレイの遷移 | 開始ファンファーレ |
| ゲームオーバー | BGM を止めて終了ファンファーレ |
| 投下・合体 | 短い電子音 |

音はすべて `audio.js` が WebAudio で合成しています。**音源ファイルを持たないので、
公開時に素材の権利を気にする必要がありません。**

左パネルの **🔊 音 ON / 🔇 音 OFF** で全部まとめて切り替わります（設定は保存されます）。
タブを裏に回している間は BGM が止まります。

### iPhone / iPad で音が出ないとき

iOS の WebAudio は環境要因で黙りやすいので、次の 2 つを入れてあります。

- **消音スイッチ** … 既定の音声セッションは本体の消音スイッチに従うため、
  スイッチが消音側だと何も鳴りません。BGM を流している間だけ
  `navigator.audioSession.type` を `playback` にして回避しています
  （BGM を止めると `auto` に戻すので、タイトル画面では他アプリの再生を邪魔しません）。
- **中断からの復帰** … 着信・Siri・アプリ切り替えなどで音声出力が止まると、
  iOS では画面操作の中でしか再開できません。止まっている間は左パネルに案内を出し、
  どこかをタップすれば復帰するようにしています。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| マウス移動 / ドラッグ | 投下位置を決める |
| クリック / タップを離す | 投下 |
| <kbd>←</kbd> <kbd>→</kbd> | 投下位置を移動 |
| <kbd>Space</kbd> / <kbd>↓</kbd> | 投下 |
| <kbd>R</kbd> / 左パネルの **↻ やり直し** | やり直し |

- **↻ やり直し** はキーボードのない端末でも使えます。進行中のプレイを
  捨ててしまうので、誤操作よけに 2 度押し（4 秒以内）で確定します。
  1 度目を押すとボタンの色と文言が変わり、放っておけば元に戻ります。
- 落ちてくるのは小さい方の 5 人（1〜5 段階目）だけ。
- 同じウマ娘同士がぶつかると 1 段階上に進化してスコアが入る（大きいほど高得点）。
- 最大の 11 段階目同士をぶつけると消滅して +500 のボーナス。
- 上部の点線（デッドライン）を越えたまま約 1.3 秒経過するとゲームオーバー。
- ベストスコア・音量・出走メンバー・選び方の設定は `localStorage` に保存されます。

## リタイア画面

- **X にポスト**：スコア・ベスト・最高到達とゲームの URL を書いた投稿画面を開きます。
  開くだけなので、実際に投稿するかは X の画面で決められます。
- **画像を保存**：見出し（スコア・ベスト・最高到達）＋そのときの盤面＋
  到達したキャラクターのアイコンを 1 枚にまとめた PNG を保存します
  （`uma-puzzle-<スコア>.png`）。投稿に画像を添えたいときはこちらから。
- **メンバー変更** / **もう一度遊ぶ**

アイコンは CORS 許可付きで読み込んでいるので canvas が汚染されず、そのまま書き出せます。

## 出走メンバーの選択

タイトル画面がそのままメンバー選択画面になっています。

**全員から選ぶ** のチェックボックスで、選び方が 2 通りに切り替わります（設定は保存されます）。

### チェックを外したとき（既定）

**各段階は、対応するグループから 1 人ずつ**選びます。
11 段階と 11 グループが 1 対 1 に対応していて、小さい段階ほど小さいグループです。

- 一覧にはいま編集中の段階の候補だけが並びます
- 検索もその段階の中だけを対象にします（圏外の名前を探すと切り替えの案内が出ます）
- **ランダム**：各グループから 1 人ずつ無作為に選び直す
- トレセン学園関係者は公式にスリーサイズの記載がなく段階を持たないため、
  このモードには出てきません

### チェックを入れたとき

推しを好きな段階に置きたいとき用。グループの制約がなくなります。

- トレセン学園関係者を含む 173 人が 1 つの一覧に並びます
- 検索も 173 人全員が対象
- **ランダム**：173 人から重複なしで 11 人

### 共通の操作

- 上部の 11 枠が現在の顔ぶれ（小さい順）。**押すとその段階が編集対象になり**、
  一覧の中身が切り替わります（選択中の枠はピンクの輪で示されます）
- 一覧のキャラクターを押すと、編集中の段階に入ります
  （他の段階にいた人を選んだ場合はその 2 人が入れ替わります）
- **初期メンバー**：下の初期構成に戻す
- 左下に「いま何段階目を編集中か」を表示しています

チェックを切り替えても顔ぶれはそのまま引き継がれます。
全員から選んだ並びのままチェックを外すこともできます
（その場合、枠にグループ外の人が入ったままになります）。

### グループ分け（内部仕様）

グループの中身は公式プロフィールのスリーサイズ（B 値）の範囲で決めていますが、
**画面上はその根拠を出していません**。段階は番号でしか呼ばず、
一覧のカードにもサイズは表示しません。

| 段階 | 内部の範囲 | 人数 | 初期メンバー |
| --- | --- | --- | --- |
| 1 | B66-71 | 7 | サイレンススズカ |
| 2 | B72-75 | 15 | ハルウララ |
| 3 | B76-77 | 14 | トウカイテイオー |
| 4 | B78-79 | 11 | ナイスネイチャ |
| 5 | B80-81 | 16 | スペシャルウィーク |
| 6 | B82-83 | 17 | オグリキャップ |
| 7 | B84-85 | 18 | キタサンブラック |
| 8 | B86-87 | 14 | シンボリルドルフ |
| 9 | B88-89 | 13 | ゴールドシップ |
| 10 | B90-92 | 13 | マルゼンスキー |
| 11 | B93-99 | 7 | ヒシアケボノ |
| （なし） | 記載なし＝トレセン学園関係者 | 28 | — |

区切りを変えたい場合は `items.js` の `BUST_GROUPS` を書き換えてください。
段階数（`SIZES` の要素数）と揃えるのを忘れずに。
範囲から外れた人がいれば下限側・上限側の受け皿グループが自動で足され、
該当者がいないグループは選択肢に出ません。

内部のグループ名（`B66-71` など）はキーとしてだけ使い、画面には出しません。
段階に対応するグループは `items.js` の `STAGE_GROUPS`
（`ROSTER_GROUPS` から関係者を除いたもの）です。

途中でメンバーを変えたくなったら、左パネルの **⚙ 出走メンバー** を押します。
プレイ中に押した場合は盤面が一時停止するだけで、**再開** でアイコンと名前だけが
入れ替わり、スコアも落ちている球もそのまま続きを遊べます
（段階ごとの大きさは顔ぶれによらないため）。
リタイア画面の **メンバー変更** はタイトルに戻り、次のランを最初から始めます。

## PWA（ホーム画面に追加）

インストールしてアプリのように遊べます。オフラインでも起動します。

- iOS: Safari の共有メニュー →「ホーム画面に追加」
- Android / デスクトップ Chrome: アドレスバーのインストールアイコン

Service Worker（`sw.js`）がアプリ本体を丸ごとキャッシュするので、2 回目以降は
ネットワークなしで起動できます。キャラクターアイコンは公式 CDN から読むため、
一度オンラインで表示したぶんだけキャッシュされます。未取得のアイコンは
オフラインではイメージカラーの円で代替表示されます。

`sw.js` や配信ファイルを変えたときは、`sw.js` の `VERSION` を上げてください。
古いキャッシュは次回起動時に破棄されます。

## 公開

`main` に push すると GitHub Actions が動き、GitHub Pages に配信されます。
`tools/` や `.claude/` などは配信対象から外し、遊ぶのに必要なファイルだけを `_site/` に集めています。
配信物を変えたときは `deploy.yml` の「公開するファイルだけを集める」ステップも合わせて直してください。

### キャラクターが増えたら

公式サイトに新キャラが追加されたら、一覧を作り直せば設定画面に出てきます。

```bash
node tools/fetch-characters.mjs
```

取得するのは名前・カテゴリ・イメージカラー・アイコンの URL だけで、画像は落としません。

### 調整したいとき

- 段階ごとの大きさ・投下できる種類数・初期メンバー … `items.js`（`SIZES` / `DROPPABLE` / `DEFAULT_PICKS`）
- 段階とグループの対応 … `items.js` の `BUST_GROUPS`（`SIZES` と同じ数だけ並べる）
- アイコンの取得解像度 … `items.js` の `ICON_W`（盤面用）と `THUMB_W`（一覧用）
- スコア計算 … `items.js` の `mergeScore()`
- BGM の曲調 … `audio.js` の `BPM` / `PROGRESSION` / `MELODY_PATTERN`
- ファンファーレ … `audio.js` の `fanfareStart()` / `fanfareEnd()`（音名は MIDI 番号）
- 音量バランス … `audio.js` の `MIX`（各パート）と `BGM_TRIM`（全体）、`game.js` の `BGM_VOLUME`
- ケースの形（U 字の深さ）・デッドライン・投下間隔 … `game.js` 冒頭の定数
  （`BOWL_R` を小さくすると角丸のバケツ型、内寸の半分にすると今の U 字）

デバッグ用に `window.UmaGame`（`startRun()` / `showTitle()` / `reset()` / `drop()` / `phase` / `engine` / `items` / `score`）を公開しています。

## 素材について

BGM・効果音は実行時に合成しているので、音の素材は同梱していません。

アイコンは公式ポータルサイトが配布しているものを表示時に読み込むだけで、
このリポジトリには同梱も再配布もしていません。
配布元の利用条件は SNS アイコン用途を想定したものなので、
このゲームを公開・配布する場合は各自で利用範囲を確認してください。
